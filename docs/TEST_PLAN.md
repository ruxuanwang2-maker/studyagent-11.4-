## 新增重点

1. 12 条历史消息只取最近 4 条且按时间展示，毫秒相同时稳定排序。
2. 外部向量重启不被覆盖；本地 query 不和外部向量混算；非法 NaN/维度批次拒绝并保留良好索引。
3. 同页阅读、同源标注更新不重复记录；20 次提问仍不能制造 mastery。
4. 新事件/章节 A/B 隔离；私密提问 opt-out 不入事件/记忆。
5. 文档替换中间失败，标题/章节/内容完整回滚。
6. 工作区对话默认 ID 与调试上下文按账号隔离；非法 JSON 返回 400 而非 500。
7. 迁移重开幂等、实际备份 integrity_check、已有标题回填；删除/课程清空/账号导出包含新对象。
8. 提问事件保存 page/selectedText/formula；页面记录拒绝零、负数、非整数。

## 实际浏览器用户模拟（本轮已运行，不是自动浏览器测试）

使用独立临时 Regression Student 账号及两页结构化讲义：登录 → 笔记学习记录 → 课程/7天筛选 → 未分类课程空结果 → 返回原资料 → 阅读两页 → 第二页提问 → 使用真实历史问题关联 → 结束学习 → 刷新 → 查看持久化经历 → 从第二页问题返回第二页 → 退出。

发现并修复：只阅读时未保存当前页，导致经历显示阅读 0 页；问题事件没有页码，来源导航可能落到第一页。修复后 API 导出断言 `pagesViewed=[1,2]`、问题来源 `page=2`，浏览器显示“阅读 2 页，产生 1 个问题”。测试账号和导入副本已清理，原用户数据保留。

开发验证截图保存在 `outputs/learning-history-regression.jpg`（忽略提交）。该截图展示的是已清理测试账号的测试时状态，不是向用户账号添加的学习记录。

上一阶段大型教材导入期间曾复现：全局 API 串行导致前端 GET 15 秒可能超时。本轮已将导入/重解析、OCR 和本地向量计算移出主线程，并将索引写入合并为事务；具体复测结果见下节。普通远程 AI 请求仍在全局队列等待，不宣称全部卡顿已消失。
