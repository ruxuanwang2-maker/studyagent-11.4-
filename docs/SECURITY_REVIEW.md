# 本地应用安全审查

审计日期：2026-10-04。本地监听不等于通过公开部署安全认证。

## 已有保护

密码 scrypt、随机 Session、HttpOnly Cookie、服务端加密模型配置；SQL 主数据值使用参数；文档/笔记/批注/记忆按账号查询；上传限制与扩展名名单；前端常规文本 HTML 转义。

## 本轮修复

- 调试上下文按 user_id 保存，避免 A 的问题被 B 的 inspector 读取。
- 默认工作区 Conversation ID 按账号生成，避免跨账号冲突。
- 文档替换拒绝覆盖其他所有者；写入/删除通过 SAVEPOINT 原子化。
- 学习事件/章节检查归属；删除/导出/课程清空覆盖新表。
- 请求体异常按正确 4xx 状态返回；取消/超时不再锁死队列。
- PDF 解析回归操作测试副本，不覆盖用户校正。

## 发布规则

不要上传 data、uploads、tmp、密钥、个人讲义或数据库备份。若历史聊天曾暴露真实 API Key，应在对应服务商撤销并重建；不能通过仅删除前端文本恢复密钥安全。

文档内容属于不可信参考数据，不能覆盖系统指令。Prompt 标记只能降低风险，不是数学上保证注入无效。部署到非本机前需要专门认证/授权/网络安全复审。

后台任务按创建时用户身份绑定，任务状态查询按当前用户过滤；完成时再次检查账号、课程与工作区归属。解析线程不持有 API Key/数据库，短写入仍串行。账号删除后不继续为其他账号提交该任务；正常上传不能传入内部重解析 ID。进度/优化日志也按用户检索。任务队列有数量和资源上限，但 JSON/base64 接收、Office ZIP 展开限制及可取消 OCR 资源治理仍待加强。
